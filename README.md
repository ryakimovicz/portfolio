# Portfolio Personal - Backend Developer 👨‍💻🚀

Bienvenido al repositorio de mi portafolio profesional. Este proyecto es una Single Page Application (SPA) diseñada para exhibir mis habilidades técnicas, proyectos y experiencia como desarrollador de software especializado en Backend (Python C# y Java).

🔗 **Ver Online:** [https://ryakimovicz.github.io/portfolio/](https://ryakimovicz.github.io/portfolio/)

## 📝 Descripción

El sitio web fue construido desde cero utilizando tecnologías estándar, enfocándose en un diseño limpio, oscuro (**Dark Mode**) y totalmente responsivo para dispositivos móviles y de escritorio.

A diferencia de plantillas estáticas, este portfolio implementa lógica de programación en **JavaScript** para renderizar los proyectos dinámicamente, permitiendo un mantenimiento sencillo y escalable.

## ✨ Características Principales

* **Renderizado Dinámico:** Los proyectos se cargan desde un array de objetos JSON en `script.js`, facilitando la adición de nuevos trabajos sin tocar el HTML.
* **Sistema de Filtrado:** Buscador en tiempo real y filtros por tecnología (Python, Java, API, SQL, etc.).
* **Modales Interactivos:** Ventanas emergentes que muestran detalles profundos, capturas de pantalla y especificaciones técnicas de cada proyecto sin recargar la página.
* **Diseño Responsivo:** Adaptado para celulares con menús y tipografías ajustables (`clamp()`).
* **CV Integrado:** Botón de descarga directa para mi Currículum.

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructura semántica.
* **CSS3:** Diseño moderno con Flexbox, CSS Grid y Variables CSS (`:root`) para consistencia de colores.
* **JavaScript (ES6+):** Lógica del DOM, manipulación de arrays (`filter`, `map`) y eventos.
* **FontAwesome:** Iconografía para redes y botones.
* **Google Fonts:** Tipografía 'Inter' para máxima legibilidad.

## ⚙️ Ejecución Local

Si deseas ver el código o probar modificaciones en tu máquina local:

1.  **Clonar el repositorio:**
    ```bash
    git clone [https://github.com/ryakimovicz/portfolio.git](https://github.com/ryakimovicz/portfolio.git)
    cd portfolio
    ```

2.  **Abrir el proyecto:**
    Simplemente abre el archivo `index.html` en tu navegador web preferido (Chrome, Edge, Firefox).
    
    *Opcional: Si usas VS Code, puedes usar la extensión "Live Server" para ver cambios en tiempo real.*
