# Portfolio Personal - Full Stack Developer 👨‍💻🚀

Bienvenido al repositorio de mi portafolio profesional. Este proyecto es una Single Page Application (SPA) diseñada para exhibir mis habilidades como **Desarrollador Full Stack**, con una sólida base en Backend y capacidad de integración Web.

🔗 **Ver Online:** [https://ryakimovicz.github.io/portfolio/](https://ryakimovicz.github.io/portfolio/)

## 📝 Descripción

El sitio web fue construido desde cero utilizando tecnologías estándar (**HTML5, CSS3, JavaScript**), enfocándose en un diseño limpio, oscuro (**Dark Mode**) y totalmente responsivo. Demuestra mi capacidad para crear interfaces de usuario funcionales sin depender de frameworks pesados.

## ✨ Características Principales

* **Frontend Dinámico:** Renderizado de proyectos vía JavaScript (JSON).
* **UX/UI:** Diseño responsivo, animaciones CSS y modo oscuro.
* **Sistema de Filtrado:** Buscador en tiempo real por tecnologías (Python, Web, Java, SQL).
* **CV Integrado:** Acceso directo a mi perfil profesional.

## 🛠️ Tecnologías

* **Web:** HTML5, CSS3, JavaScript (ES6+).
* **Herramientas:** Git, GitHub Pages, FontAwesome.
